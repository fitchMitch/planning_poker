# RetourFeedback

Bandeau de confirmation affiché juste après une réponse ou une action.

## Variantes

- **Succès** : `success` / `on-success`, icône de validation.
- **Erreur** : `danger` / `on-danger`, icône d'erreur, toujours accompagné
  d'une phrase qui explique pourquoi (pas seulement « Faux »).

## Règles

- Apparaît près de l'élément concerné, jamais en popup bloquante pour une
  erreur récupérable.
- Reste visible au moins 2 secondes avant de pouvoir être ignoré, pour
  laisser le temps de lire.

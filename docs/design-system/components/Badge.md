# Badge

Jalon ou récompense débloqués (badge de compétence, série de bonnes réponses).

## Règles

- Utilise `accent` / `on-accent`, jamais `primary` — garde le signal de
  récompense distinct de l'action courante.
- Toujours associé à un libellé court (« 5 bonnes réponses »), jamais une
  icône seule.
- Forme `radius-pill`.
